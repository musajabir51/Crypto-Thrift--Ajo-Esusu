# Crypto Thrift (Ajo/Esusu)
A decentralized rotating savings group implementation on Stacks blockchain.

## 🌟 Features

- Member registration with position selection
- Automated contribution tracking
- Secure fund distribution
- Complete cycle management
- Member statistics and cycle information

## 🔒 Security Features

- Owner-only administrative functions
- Input validation and bounds checking
- Protected fund distribution
- Cycle state management
- Member verification

## 🚀 Getting Started

1. Install Clarinet
```bash
curl -L https://github.com/hirosystems/clarinet/releases/download/v1.0.0/clarinet-linux-x64.tar.gz | tar -xz
```

2. Initialize project
```bash
clarinet new crypto-thrift && cd crypto-thrift
```

3. Deploy contract
```bash
clarinet deploy
```

## 📝 Testing

Run the test suite:
```bash
clarinet test
```
